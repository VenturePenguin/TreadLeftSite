Changelog

Release Notes

A running history of updates, fixes, and new features in the TreadLeft app.

Version 1.6.7

Latest
  • AI Running Coach: New dashboard card that analyzes your weekly mileage, injury risk, and shoe wear to deliver personalized training tips you can rate and improve over time.
  • Dashboard refreshed with a cleaner 2 by 2 metrics grid.
  • Weekly Volume and Cost per Distance now switch automatically between miles and kilometers based on your preference.
  • Improved light and dark mode consistency across the Shoes segmented control and floating tab bar.
  • Market deal cards now show more reliable brand logos and correct local currency matching.

Version 1.6.1 - 1.6.0

  • iOS build number bumped to 309 for the 1.6.0 release, with subsequent build updates to 317 for distribution.

Version 1.5.5

  • Major feature accumulation including new Loadout, Graveyard, and Analytics tabs.
  • Push notification infrastructure added.
  • Affiliate deal pipeline and iOS/Android build pipeline improvements.

Version 1.5.0

  • iOS build stability improvements including Expo pod modular headers and SDK 54 dependency fixes.
  • Fix for black screen on launch via makeKeyAndVisible and retain factory changes.

Version 1.3.3 - 1.3.2

  • Strava stability and real pricing integration. Hardened Row Level Security policies to prevent user data loss.
  • Self-healing sync logic added to force a fresh Strava sync when no shoes are detected locally.
  • Affiliate scraper moved from mock data to live retailer pricing via SerpApi.
  • Backend infrastructure deployed for Price Alerts including database triggers and email notifications.

Version 1.2.14 - 1.2.2

  • Injury Risk Indicator added to the Analytics screen with a speedometer gauge.
  • Animated entrance added to the Rotation Health donut chart.
  • Apple Sign-In button hidden where required and OAuth flow hardened to prevent login hangs.
  • SQL migrations, Edge Functions, assets, and utility files synchronized for production builds.

Version 1.0.16 - 1.0.3

  • Strava sync race conditions resolved, including duplicate shoe prevention and initial sync reliability.
  • Delete shoe, back button, and View in Strava activity linking improvements.
  • App icon and TreadLeft logo clipping issues corrected for store compliance.
  • Mileage sync corrected to use total distance from Strava gear.
  • Connection screen hang fixed by removing blocking auth logic.

Version 1.0.0 - 1.0.2

Initial App Store and TestFlight releases of TreadLeft. Core features included Strava connection, automatic shoe mileage tracking, and basic health status alerts.
